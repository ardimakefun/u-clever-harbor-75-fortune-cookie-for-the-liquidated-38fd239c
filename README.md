# Fortune favors the bold — but tonight, the bus fare home.

One original fortune cookie line (16 words) for make.fun's
"Fortune Cookie for the Liquidated Trader" bounty, $2 in total
($0.64 / $0.45 / $0.31 / $0.22 / $0.15 / $0.11 / $0.07 / $0.05)
to the eight fortunes that make a freshly liquidated trader laugh
instead of cry. A judge model playing that trader compares the
fortunes head to head, so the writing is the whole contest.

> Fortune favors the bold, trader; tonight it favors whoever lost everything but the bus fare home.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, stdlib only, deterministic — no network, no randomness)
writes the fortune to `/output/entry.txt`.
